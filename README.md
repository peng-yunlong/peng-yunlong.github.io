# Yunlong Peng — Academic Website

This repository contains the source code for [Yunlong Peng's academic website](https://peng-yunlong.github.io/).

The site is built with Jekyll using the Academic Pages / Minimal Mistakes framework. Personal content is maintained primarily in:

- `_pages/about.md`
- `_pages/publications.md`
- `_config.yml`
- `files/CV-Yunlong.pdf`

The generated `_site/` directory should not be committed. Theme attribution and licensing information are retained in `LICENSE.md`.
